# T099 — xác nhận quy ước phía frontend P5

P5 xác nhận D1–D4 trong `docs/contracts/api-conventions.md`: decode failure dùng 422; timeout prediction 15 giây và health/model-info 5 giây; có fallback cho error code lạ; type viết tay và kiểm tra drift. Việc xác nhận quy ước chưa có nghĩa T040 đã hoàn thành.
